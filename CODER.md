# WakaTime Setup Guide

[WakaTime](https://wakatime.com) automatically tracks your coding activity across editors and displays it on your GitHub profile.

## Quick Start

1. **Sign up** at [wakatime.com](https://wakatime.com/signup)
2. **Install plugin** for your editor:
   - VS Code: [WakaTime extension](vscode:extension/WakaTime.vscode-wakatime)
   - JetBrains: Install from marketplace
   - Vim/Neovim: `:Plug 'wakatime/vim-wakatime'`
   - See all: [wakatime.com/plugins](https://wakatime.com/plugins)
3. **Get API key** from [wakatime.com/settings](https://wakatime.com/settings)
4. **Enter API key** when your editor prompts you

## Enable in README

In `README.md`, remove the comment markers around the WakaTime section:

```markdown
<img src="https://github-readme-stats.vercel.app/api/wakatime?username=Clement-ccy&title_color=47645f&text_color=a8a39c&bg_color=1f2124&border_color=2a2d31&layout=compact" alt="WakaTime">
```

Replace `Clement-ccy` with your actual WakaTime username.
